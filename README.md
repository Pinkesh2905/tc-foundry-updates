# TC Foundry updates

This repository only hosts the **update files** for TC Foundry (see Releases). It contains no source code.

Each release has:

- `TC-Foundry-Update-x.y.z.tcupdate` — a signed update file. TC Foundry installs it only if it was signed by Vezapp, and only on a computer that has a TC Foundry licence.
- `latest.json` — the small list that TC Foundry reads to find the newest version.

You do not need to download anything here yourself. In TC Foundry, an administrator opens **Updates** and presses **Check for updates**.
